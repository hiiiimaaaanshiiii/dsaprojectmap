# Map Navigator — GitHub Upload

This is the lightweight source-code package for the Map Navigator project.

## Upload to DSAPROJECT
1. Extract this ZIP on your computer.
2. Open https://github.com/hiiiimaaaanshiiii/DSAPROJECT.
3. Choose **Add file → Upload files**.
4. Drag the extracted project contents into the upload area.
5. Commit the changes to `main`.

## Large map datasets
The full `delhi_ncr.osm` source extract and `delhi_ncr_graph.csv` generated graph are not included. They are large and should be kept locally or shared separately using Git LFS or a release asset. The included `delhi_demo_graph.csv` is sufficient to compile and test the project. See `backend/data/README.md` for details.

The `.gitignore` excludes dependencies, build output, local environment files, and macOS metadata.
