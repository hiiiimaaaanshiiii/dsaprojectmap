# Map Navigator — GitHub Upload

This folder contains the cleaned Map Navigator project.

## Upload to DSAPROJECT
1. Open https://github.com/hiiiimaaaanshiiii/DSAPROJECT
2. Choose **Add file → Upload files**.
3. Extract this ZIP on your computer.
4. Drag the contents of the extracted folder into the GitHub upload area.
5. Commit the changes to `main`.

The `.gitignore` excludes dependency folders, build output, local environment files, and macOS metadata from future commits. Install dependencies locally with `npm install` before running the frontend. Build the C++ backend using the included Makefile.
